Put your app assets here:

REQUIRED before first build:
  - icon.png             1024×1024 (app icon)
  - adaptive-icon.png    1024×1024 (Android foreground, transparent)
  - splash.png           1284×2778 (splash screen image)
  - notification-icon.png 96×96 (Android notification icon, monochrome white)
  - favicon.png          48×48 (web)

You can generate placeholders quickly:
  npx expo install expo-app-icon-utils  # optional helper
or use https://www.appicon.co/ to generate from a single 1024px source.
